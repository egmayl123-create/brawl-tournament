ТОРНИРНЫЙ САЙТ — БЫСТРЫЙ ЗАПУСК

1. Установи Node.js LTS.
2. Открой терминал в этой папке.
3. Задай пароль организатора:
   Windows PowerShell:
   $env:ADMIN_PASSWORD="ТВОЙ_ПАРОЛЬ"
4. Запусти:
   npm start
5. Открой:
   http://localhost:3000/
   — страница для участников
   http://localhost:3000/admin
   — админка организатора

Участники могут только смотреть. Изменение счётов отправляется на сервер и сохраняется в data/state.json.
Для публикации в интернете нужен Node.js-хостинг, который поддерживает постоянную запись файла (например VPS/Render/Railway). Перед публикацией обязательно поменяй ADMIN_PASSWORD.

ВАЖНО:
Текущая версия использует существующую структуру твоего HTML и текущие 4 группы по 3 игрока. Состав и результаты хранятся в data/state.json.
